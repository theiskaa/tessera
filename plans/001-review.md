# Phase 001 review — 2026-09-26

## What changed

- `internal/bench/silver/measure.sh` now prints exact F1, lenient precision,
  lenient recall, and lenient F1 under separate names. Its fresh GB address row
  reads 64.2, 84.8, 97.9, and 90.9 respectively.
- `trainer eval --gold` now accepts `--country-hint-mode known|auto`, defaults to
  `known`, and records the mode in JSON and Markdown. Auto mode passes an empty
  country hint to Tessera while retaining gold country for score slices.
- `bench/web/measure.py --bundle` serves either existing candidate directly and
  records its path and SHA-256. It rejects missing and out-of-repo paths.
- The ignored aggregate report at `internal/reports/m7/v17-decision.md` is
  regenerated by `make_v17_decision.py` from named evaluation and browser files.

## Verification

- `cargo test -p trainer detect_eval`: 6 passed, including a national GB phone
  that is found with a known-country hint and missed in auto mode.
- `cargo fmt --all --check`, `cargo build --release -p trainer`, `just wasm`,
  `sh -n internal/bench/silver/measure.sh`, Python compile checks, and
  `git diff --check`: all passed. The selected bundle path rejects an escape
  outside the repo.
- Fresh v16 and v17 known-hint evaluations matched all 25 country-and-kind
  rows in their prior reports. The v17 auto evaluation used the same 877 gold
  documents. Rebuilding `gold-all.jsonl` left its SHA-256 unchanged.
- Both Chrome runs passed the harness checks with the same Chrome version,
  package build, host, fixture, and 20 warm calls. The JSONs identify distinct
  bundle hashes. Parser development errors were counted by country and label;
  no test-half example was used for diagnosis.
- `git status --short` shows no new model or site modification. The two
  detector config edits were already present before this phase. No training
  command ran.

## Findings and limits

- V17 SIMD worker warm median/p95 is 475/500 ms on the desktop fixture, versus
  the 150 ms target. The environment and exact figures are in the scorecard;
  mobile latency is still unmeasured.
- US phone recall falls from 98.2% with the gold country supplied to 76.0% in
  default auto mode. This is a real product-path risk; a country-hinted score
  cannot stand in for default-query quality.
- V17 still misses most per-country people, address, and parser targets. It
  changed two training inputs at once, so this comparison does not identify
  which change caused an individual gain or regression.
- The scorecard is an evaluation record, not a release approval. Real contact
  cards and false cards are Phase 002 work. Runtime profiling and an
  output-preserving optimization are needed before another wider model.
