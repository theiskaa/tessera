# Phase 017 checkpoint review — 2026-09-26

The reviewed-document evaluator now records a separate `lenient_one_to_one` precision, recall, and F1 in JSON. Maximum-cardinality overlap matching runs within each document and kind. The original `lenient` counts and Markdown columns remain unchanged so V17/V19c's frozen primary comparison is not silently redefined. Exact matching now limits a duplicated external prediction to one true positive per gold span; ordinary nonduplicate output is unchanged. Scoring rejects a missing prediction list instead of silently truncating cases. Both cardinality failure patterns, an augmenting path, and duplicate exact predictions pass a focused unit test; all seven `detect_eval` tests pass.

`cargo fmt --all --check`, `cargo clippy -p trainer --all-targets -- -D warnings`, and `git diff --check` pass. An independent scan of all 877 frozen gold cases found no duplicate case names, duplicate spans, empty spans, unknown kinds, or same-kind gold overlaps.

The rebuilt release trainer scored V17 on the frozen 877-document set in auto country-hint mode. Every five-country person/address `exact` and legacy `lenient` score equals the prior V17 report, confirming the primary comparison is unchanged. The new one-to-one address lenient recall equals legacy recall in US, GB, GE, and JP; DE is 92.9% versus 93.7% legacy, a 0.8-point gap. One-to-one address precision is lower by 0.8 points in US, 5.1 in GB, 3.8 in DE, 3.8 in GE, and 2.6 in JP. Thus the old many-to-many overlap mostly inflated precision here; it does not explain the large GE recall gap. This evaluation ran during GPU training, so its latency data is invalid for performance conclusions. Private report: `internal/reports/m7/v17-auto-one-to-one-release.md` and JSON under `runs/eval-v17-auto-one-to-one-release/`.

The same rebuilt evaluator subsequently scored V19c on the frozen development set. Georgian address one-to-one recall rose 57.2% to 67.8%, exactly the legacy lenient-recall delta; the finding is therefore not a many-to-many overlap artifact. The V17 legacy scores matched the prior reference, and the host-annotated copy left ordinary V17 and V19c scores unchanged. This completes Phase 017's evaluation check but does not establish a new product accuracy claim.
